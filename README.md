# Airbnb Hotel Booking Analysis

## Project Overview
This project analyzes Airbnb listings to understand pricing trends, neighborhood distribution, host behavior, customer reviews, and availability patterns.

## Objectives
- Analyze Airbnb listing distribution
- Study pricing trends across neighborhoods
- Examine host performance
- Explore customer review patterns
- Identify relationships between price, service fee, and availability

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Insights
- Manhattan has the highest number of listings.
- Entire Home/Apt is the most common room type.
- Price and service fee show a strong positive correlation.
- Host verification has minimal impact on review ratings.
